# Routing Prototyp

Wird hier neu aufgebaut. Ziel: Sportwagen Profil gegen ein calimoto ähnliches Motorrad Profil vergleichen und die Untergrenze für schmale Straßen an echten Strecken kalibrieren.

Erster Stand (3. November 2026, Nordschwarzwald, 5 Testrouten): Sportwagen Profil 3,3 km auf vermutlich schmalen Abschnitten statt 21,5 km, schlechter Belag 0,2 km statt 3,1 km, bei rund 7 % mehr Strecke. Details im Projektkontext.

Geplant:
* Breitenregler mit drei Stufen: breit, schmal okay, Abenteuer
* Kalibrierung an Korays Beispielstraßen ("schmal und super", "zu schmal")
* Super Plus Tankstellen und Aussichtsparkplätze als Stopps
* Später: Übergang zu GraphHopper Custom Model
